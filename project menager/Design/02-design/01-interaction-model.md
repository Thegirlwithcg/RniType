# 02.1 — โมเดลการใช้งาน

## 1. แกนความคิดหลัก: 8 × 8 ไม่ใช่ 8 + 8

การพิมพ์หนึ่งตัวอักษร = **สองการตัดสินใจที่เกิดพร้อมกัน**

```
LS ทิศ = กลุ่ม (กลุ่มละ 8 ตัว) — เลื่อนเปลี่ยนกลุ่มได้ขณะดันค้าง
RS ทิศ = ลำดับที่ในกลุ่ม (1..8)
ปล่อย RS กลับเข้าศูนย์ = พิมพ์
```

- จำนวนช่องทั้งหมด = 8 × 8 = **64 ตัวอักษร** ต่อชั้น (layer)
- ไม่มีการกดปุ่มยืนยันเพิ่ม: การปล่อยมือคือการยืนยัน
- ถ้าปล่อย LS ก่อน RS → ยกเลิก ไม่พิมพ์ (กันการพิมพ์พลาด)

## 2. ลำดับเหตุการณ์ของการพิมพ์ 1 ตัว (canonical gesture)

1. ดัน LS ไปทิศที่ต้องการ (เกิน deadzone 0.35) → HUD แสดง 8 ช่องของกลุ่มนั้น
2. ดัน RS ไปทิศของตัวอักษร (เกิน 0.40) → HUD ไฮไลต์ตัวที่เลือก + preview ที่ cursor
3. ปล่อย RS กลับเข้าใกล้ศูนย์ (< 0.25 ค้าง 60 ms) → ส่งคีย์
4. ปล่อย LS กลับศูนย์ → กลับสู่ idle

> **เปลี่ยนกลุ่มระหว่างทางได้**: ขณะ LS ยังดันอยู่ เลื่อนไป sector อื่น = เปลี่ยนกลุ่มทันที
> (HUD เปลี่ยนชุดตัวอักษร, ตัวที่เลือกถูกยกเลิก) — ไม่ต้องปล่อยแล้วดันใหม่
> ดู [[09-ls-switch-group]]

**ทางยกเลิก 3 ทาง**
- ดัน RS ค้างในภาคเดิม > 600 ms → ยกเลิก (ไม่พิมพ์) และไม่ repeat
- ปล่อย LS ก่อน (RS ยังอยู่) → ยกเลิก
- กด B (Backspace) ขณะเลือก → ยกเลิก

**Auto-repeat**: ถ้า LS ยังค้างและ RS ค้างที่ทิศเดิมหลังพิมพ์ → พิมพ์ซ้ำอีกครั้งหลัง 350 ms
แล้วทุก 90 ms (ใช้กับ `-----`, `.....`, ตัวอักษรซ้ำ)

## 3. ทำไมต้องมี mode (แก้ข้อขัดแย้งใน canvas)

canvas กำหนดให้ **RS เลือกตัวอักษร** แต่ก็ให้ **RS เลื่อนเมาส์** เช่นกัน
และ **RB/RT = คลิกซ้าย/ขวา** ซึ่งขัดกับ LB/LT = Ctrl/Shift ถ้าใช้พร้อมกันตลอด
→ จึงแยกเป็น mode และใช้ **D-pad ←** เปิดวงคำสั่ง (สลับ mode) — เลือกด้วย **RS** ([[10-command-wheel-rs]])

| mode | LS | RS | RB / RT | ใช้เมื่อ |
| --- | --- | --- | --- | --- |
| **Type-EN** | เลือกกลุ่ม (QWERTY) | เลือกตัวอักษร | ไม่ทำงาน (กันพลาด) | พิมพ์ละติน/โค้ด |
| **Type-&#8203;&lt;lang&gt;** | เลือกกลุ่มของภาษานั้น | เลือกตัวอักษร | ไม่ทำงาน | พิมพ์ภาษาที่ติดตั้ง |
| **Mouse** | scroll (บน/ล่าง) | เลื่อน pointer | คลิกซ้าย / คลิกขวา | ชี้เป้า ลาก เลือก |
| **Place UI** | เลื่อน UI หยาบ (pivot) | เลื่อน UI ละเอียด (pivot) | — | วางตำแหน่ง HUD |

**ภาษา (v0.11)**

- ภาษาที่ติดตั้งใน Windows ปรากฏใน **วงภาษา** (D-pad ← → ช่อง Language) — สูงสุด 8 ภาษา
- **ตรวจตอนเริ่มแอป**: ถ้าไม่มี layout ที่สอง → มีแค่ English; เครื่องไทย → English + Thai (ค่าเริ่มต้นม็อกอัป)
- **ภาษา layout** (ไทย, รัสเซีย, กรีก, …): map ตัวอักษรจาก QWERTY/ตารางเริ่มต้น — แก้ได้ในหน้าตั้งค่า
- **ภาษา IME** (ญี่ปุ่น, เกาหลี, จีน): HUD แสดงแป้น QWERTY และ **ส่งคีย์เหมือนคีย์บอร์ดจริง**
  ให้ Windows IME ประกอบเอง (candidate window เป็นของ OS) — แสดง badge `IME`
- ไทยยังใช้ตาราง 8×8 ที่ออกแบบไว้เป็นค่าเริ่มต้น ([[12-thai-tone-and-below-vowel]])
- ดู [[14-universal-languages]]

**การเลือก/แก้ข้อความ (v0.6)**

- **ไม่ดัน LS → RS ว่าง** โดยค่าเริ่มต้น (กัน caret/บรรทัดเลื่อนโดยไม่ตั้งใจ)
  - **กด R3 1 ครั้ง = เปิดลูกศร** (RS ↑↓←→ ย้าย caret, กดค้าง repeat 90 ms) · **กดอีกครั้ง = ปิด**
  - **กด R3 สองครั้งติดกัน (< 300 ms) = โหมดเลือกข้อความ** (เปิดลูกศรให้อัตโนมัติ)
- **Mouse mode: RB + RS = คลิกแล้วลาก** — กด RB ลงที่จุดหนึ่งแล้วเลื่อน RS = เลือกช่วงข้อความ (เหมือนลากเมาส์)
- A = ยืนยัน · B = ยกเลิก, พิมพ์ทับหรือ Backspace ขณะมี selection = แทนที่/ลบทั้งช่วง
- ชนิดของข้อความที่เลือกใช้ `selAnchor` เดียวกับ typing — ไม่มี state ซ้อน

- **D-pad ← = เปิด "วงคำสั่ง" ในวงใน** (แตะซ้ำ = ปิด) — 8 ช่อง: ↑ EN · ↗ Other language · → Mouse · ↘ Place UI · ↓ Copy · ↙ Paste · ← Undo · ↖ Redo
- **ช่องภาษาอื่น**: มี 1 ภาษา → แสดงรหัสนั้นและสลับทันที · มากกว่า 1 → `Lang` เปิดวงภาษา · **มีภาษาเดียว → ไม่มีช่องนี้**
- **เลือกด้วย RS (อนาล็อกขวา)**, **ปล่อย RS = ยืนยัน** (dwell 60 ms) · **A = ยืนยันทันที** · **B = ยกเลิก**
- **LS ไม่มีผลในวงคำสั่ง/วงภาษา** — กันการเปลี่ยนคำสั่งโดยไม่ตั้งใจ (ดู [[10-command-wheel-rs]])
- ภาษาที่ใช้ IME: HUD แสดง QWERTY และส่งคีย์ให้ OS IME ประกอบ ([[14-universal-languages]])
- ถ้าเปิดวงขณะ RS ยังดันค้าง วงจะยังไม่เลือกช่องใด จนกว่าจะปล่อย RS กลับศูนย์หนึ่งครั้ง (กันคำสั่งพลาด)
- ทางลัดที่ย้ายออกจากวง: วงล้อ 2 = **RB/RT**, Quick bar = **LB ค้าง**, HUD/พัก = หน้าตั้งค่า/tray
  → **หลักเดียว: วงใน = สิ่งที่ LS เลือก (ยกเว้นวงคำสั่ง = RS) · วงนอก = สิ่งที่ RS เลือก** (ดู [[07-dpad-left-command-wheel]])

## 4. ปุ่มหน้า (X / Y / A / B) — เติมช่องที่ canvas ยังไม่กำหนด

ปุ่มเหล่านี้ **ทำงานทุก mode** เพราะเป็นปุ่มที่นิ้วโป้งขวาแตะได้โดยไม่ต้องละแกน

| ปุ่ม | Xbox | DualSense | หน้าที่ |
| --- | --- | --- | --- |
| A | A | ✕ (Cross) | **Space** (แตะ) / Enter (แตะเร็ว 2 ครั้ง) |
| B | B | ○ (Circle) | **Backspace** (แตะ) / ลบทั้งคำ (กดค้าง 400 ms) |
| X | X | □ (Square) | **Enter** |
| Y | Y | △ (Triangle) | **Tab** (แตะ) / Esc (กดค้าง) |

> เหตุผล: 3 ปุ่มนี้ถูกใช้ถี่กว่าตัวอักษรใดๆ ถ้าต้องผ่านแกนจะเสียเวลามาก
> และทำให้ "พิมพ์ผิด → ลบ → พิมพ์ใหม่" ทำได้ในจังหวะเดียว

## 5. ตัวปรับ (Modifiers)

| จอย | คีย์ | หมายเหตุ |
| --- | --- | --- |
| LT / L2 | **Shift (toggle)** | กดครั้งเดียว = ล็อกตัวพิมพ์ใหญ่, กดอีกครั้ง = ตัวเล็ก · UI แสดง `ตัวใหญ่` ([[13-shift-toggle]]) |
| LB / L1 | **Ctrl** | ตาม canvas; ใช้กับ "Quick bar" ด้านล่าง |
| LT + LB | Ctrl + Shift | สำหรับคีย์ลัดที่ต้องใช้ทั้งคู่ |

**Quick bar (กด LB ค้าง)** — HUD เปลี่ยนเป็น 8 ช่องทางลัดบน RS:

| ทิศ | การทำงาน |
| --- | --- |
| ↑ | Copy (Ctrl+C) |
| ↗ | Paste (Ctrl+V) |
| → | Cut (Ctrl+X) |
| ↘ | Undo (Ctrl+Z) |
| ↓ | Redo (Ctrl+Y) |
| ↙ | Select All (Ctrl+A) |
| ← | Save (Ctrl+S) |
| ↖ | Switch window (Alt+Tab) |

- ถ้าใน Quick bar ดัน LS ด้วย = โหมด "Ctrl + ตัวอักษร" ทั่วไป (Ctrl+ ตัวที่เลือกจาก keymap)
- **Alt** ยังไม่มีที่ยึด: เสนอ hold-Y (Tab) + ทิศ = Alt+Tab/Alt+F4 หรือใช้ View/Share button
  → ดู [[01-open-questions]] Q5

## 6. HUD (จำเป็นต่อการเรียนรู้)

Overlay โปร่งใส คลิกทะลุได้ แสดงเฉพาะตอนใช้จอย — **โฟกัสทีละชั้น (v0.9) + pivot (v0.10) + หลายภาษา (v0.11)**:

1. **ตำแหน่ง**: ตรึงที่ **pivot** ไม่ตามเมาส์ — ย้ายด้วยโหมด Place UI ([[11-hud-pivot-nav]])
2. **Idle**: จุด cursor + pill สถานะ (`Type EN`) เท่านั้น — ไม่มีวง (เปิด "แสดงวงตลอดเวลา" ได้)
3. **วงใน (LS)**: 8 กลุ่มอักษร + ชื่อกลุ่ม — กลุ่มที่ armed เด่น กลุ่มอื่นจาง
4. **วงนอก (RS)**: 8 ตัวอักษรของกลุ่มที่เลือก / 8 ทางลัดของ Quick bar
5. **วงคำสั่ง** (D-pad ←): 8 ช่อง เลือกด้วย RS · **วงภาษา** (level 2): รหัสภาษาที่ติดตั้ง
6. **Preview**: ตัวอักษรที่จะได้ที่ตำแหน่ง caret (ไม่มี ghost บินแล้ว)
7. **แถบสถานะ**: pill บรรทัดเดียว — mode · ภาษา · สิ่งที่เลือก · modifier (ชั้น 2 / UPPER / IME / ลูกศร)
8. **สระล่าง (ุ ู)**: มีขีดกำกับเหนือตัวอักษร ([[12-thai-tone-and-below-vowel]])
9. **Settings window**: หน้าต่างแยก ภาษาอังกฤษ (General/Languages/Keymap/HUD + Reset)
10. หายไปใน 800 ms หลังพิมพ์ครั้งสุดท้าย (ปรับได้), เปิด/ปิดด้วยปุ่มค้าง LT+RT

> ระหว่างเรียนรู้ควรเปิดตลอด; ผู้ใช้ขั้นสูงปิดได้และยังพิมพ์ได้เพราะไม่ต้องมอง

## 7. กรณีขอบที่ต้องจัดการ

| สถานการณ์ | พฤติกรรม |
| --- | --- |
| ข้อความ focus อยู่ที่ช่องที่พิมพ์ไม่ได้ | ยังส่งคีย์ (OS จัดการ) แต่ HUD เตือนสีเทา |
| สลับ mode กลาง gesture | ยกเลิก gesture ปัจจุบัน ไม่พิมพ์ |
| เลื่อน LS ไปกลุ่มอื่นระหว่างดันค้าง | เปลี่ยนกลุ่มทันที, ยกเลิกตัวที่เลือก, ไม่พิมพ์ |
| เปิดวงคำสั่งขณะ RS ยังดันค้าง | วงไม่เลือกช่องใด จนกว่าจะปล่อย RS กลับศูนย์ (กันคำสั่งพลาด) |
| เปิดวงคำสั่งแล้วดัน LS | ไม่มีผล (วงคำสั่งใช้ RS เท่านั้น) |
| ย้าย pivot ในโหมด Nav | UI ขยับตาม แต่ไม่กระทบข้อความ/pointer |
| พิมพ์ภาษาที่ใช้ IME | HUD ส่งคีย์ QWERTY ให้ Windows IME ประกอบ — ไม่มี preview ตัวอักษรจาก HUD |
| ภาษาที่ติดตั้งถูกปิดใน Settings | หายจากวงภาษา; ถ้าเป็นภาษาปัจจุบัน → กลับ EN |
| ถอดจอยกลางคัน | คืนค่า modifier ทั้งหมด, หยุดส่ง, HUD แจ้ง |
| หน้าต่าง elevated (Task Manager, UAC) | ส่งไม่ได้ (UIPI) → เตือนให้รันแบบ admin |
| ผู้ใช้ใช้คีย์บอร์ดจริงพร้อมกัน | ไม่บล็อก; จอยทำงานเสริม |
| กดปุ่มปิดฉุกเฉิน (LB+RB ค้าง 1.5 s) | หยุดรับ input 3 วินาที + HUD แจ้ง |
