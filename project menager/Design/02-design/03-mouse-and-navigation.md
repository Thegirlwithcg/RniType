# 02.3 — เมาส์และการนำทาง

## 1. สูตรการเลื่อน pointer

```
a      = (ax, ay)                     # ค่าดิบจาก RS, -1..1 (หลัง normalize)
m      = hypot(ax, ay)
dz     = 0.15                          # deadzone
gamma  = 1.7                           # ความชันของความเร่ง
vmax   = 1600 px/s                     # ความเร็วสูงสุด (profile ปกติ)

ถ้า m < dz:  v = 0
ไม่ใช่:       s = (m - dz) / (1 - dz)
              v = vmax * s^gamma
              dir = a / m
              d = dir * v * dt             # dt จากเวลา polling จริง
```

- **ไม่มี OS pointer acceleration** ของ Windows เข้ามาเกี่ยวข้อง — เราคุมเองทั้งหมด
  (ปิด "Enhance pointer precision" ในผลของเราโดยใช้ SendInput แบบ relative)
- **Smoothing**: `d_out = lerp(d_prev, d, 0.5)` ที่ 250 Hz — กันสั่น แต่ไม่หน่วงเกิน
- **Precision mode**: กด LT ค้าง → `vmax × 0.3` (สำหรับเลือกตัวอักษร/ลากเส้น)
- **Turbo**: กด LB ค้าง → `vmax × 1.8` (ข้ามจอใหญ่)

## 2. ตารางค่าที่ต้องวัดจริง (ไม่ใช่เดา)

| ค่า | เริ่มต้น | ช่วงที่ยอมรับ | วัดอย่างไร |
| --- | --- | --- | --- |
| `dz` | 0.15 | 0.10–0.22 | วางนิ้วแตะโดยไม่ตั้งใจ → cursor ต้องไม่ขยับ |
| `gamma` | 1.7 | 1.4–2.2 | เวลากด Fitts target ระยะ 300–1200 px |
| `vmax` | 1600 px/s | 900–3500 | ระยะทาง/เวลาที่ใช้ข้ามจอ 1920 px < 1.5 s |
| smoothing | 0.5 | 0.3–0.7 | jitter (px RMS) เมื่อค้างนิ้ว |

## 3. หลายจอ (Multi-monitor)

- ใช้พิกัด **virtual desktop** (X: ลบได้), ไม่ clipping ที่ขอบจอแรก
- ใช้ DPI-aware: แปลง px ตามจอที่ pointer อยู่ (`GetDpiForMonitor`)
- **กด RS (L3)** → pointer กลับกลางจอหลักทันที (ตาม canvas) พร้อม HUD flash
- **กด RS ค้าง 600 ms** → วนไปจอถัดไป (กลางจอ) — ทางลัดเมื่อจอไกล
- ตัวเลือก "edge resistance" 3 px ที่ขอบจอ (ปิดได้) กัน pointer ลอดไปจอข้างโดยไม่ตั้งใจ

## 4. ปุ่มคลิก

| อินพุต | ผล |
| --- | --- |
| RB | คลิกซ้าย (กด = down, ปล่อย = up → ลากได้) |
| RT | คลิกขวา (Analog trigger: ผ่าน 0.4 = down) |
| RB แตะ 2 ครั้ง | **sticky drag** (ลากค้างโดยไม่ต้องกด) — แตะอีกครั้งเพื่อปล่อย |
| LB + RB | ดับเบิลคลิก |
| LT + RB | คลิกซ้ายแบบ Shift-select (เลือกช่วง) |
| RS (L3) | กลับกลางจอ (ไม่ใช่คลิก) |
| LT + RT | เมนูบริบทแบบคีย์บอร์ด (Shift+F10) |

> Analog trigger ต้องมี threshold + hysteresis (down 0.4 / up 0.2) ไม่งั้นจะคลิกซ้ำ

## 5. Scroll

อยู่ใน **Mouse mode** เท่านั้น (Nav ถูกเปลี่ยนเป็นโหมดจัดตำแหน่ง UI — ดู §6):

| อินพุต | ผล |
| --- | --- |
| LS ↑ / ↓ | scroll แนวตั้ง 1 notch ต่อ 40 ms, เร่งเป็น 3 notch หลัง 500 ms |
| LS ← / → | scroll แนวนอน |
| LS ↖ | ไปบนสุด (Ctrl+Home) |
| LS ↘ | ไปล่างสุด (Ctrl+End) |
| LT + LS | scroll ละเอียด (1 notch ต่อ 120 ms) |

> ใช้ LS ไม่ใช่ RS เพื่อไม่ให้ pointer กระโดดขณะ scroll

## 6. Nav mode = Pivot (จัดตำแหน่ง UI)

HUD ตรึงที่ **pivot** ไม่ตามเมาส์ — Nav ใช้ย้าย pivot ไปตำแหน่งที่อ่าน/พิมพ์สะดวก

| อินพุต | ผล |
| --- | --- |
| LS | เลื่อน UI หยาบ (~900 px/s) |
| RS | เลื่อน UI ละเอียด (~320 px/s) |
| LT + (LS/RS) | precision (×0.35) |
| R3 / R | UI กลับตำแหน่งเริ่มต้น |
| RB / RT | ไม่ทำอะไรในโหมดนี้ |

- crosshair แสดงที่ pivot เฉพาะโหมด Nav
- pivot ถูก clamp ให้วง HUD อยู่ในจอ (margin 172 × scale) และ clamp ใหม่เมื่อ resize/สเกล
- pointer (เมาส์) ไม่ขยับในโหมดนี้ และถูกซ่อนนอกโหมด Mouse

## 7. เลือก/แก้ข้อความด้วยจอย (v0.4)

Type mode แยกหน้าที่ของ RS ตามว่ามีการดัน LS หรือไม่:

| สถานะ | อินพุต | ผล |
| --- | --- | --- |
| ไม่ดัน LS | RS | ไม่ทำอะไร (กัน caret เลื่อน) — ต้อง **กด R3 1 ครั้งเปิดลูกศรก่อน** |
| เปิดลูกศรแล้ว | RS ↑ ↓ ← → | ย้าย caret — ↑↓ คงคอลัมน์เดิม, กดค้าง repeat 360/90 ms |
| เปิดลูกศรแล้ว | R3 อีกครั้ง | ปิดลูกศร (RS กลับเป็นว่าง) |
| ดัน LS | LS | เลือกกลุ่ม (วงใน) — เลื่อนไป sector อื่น = เปลี่ยนกลุ่มทันที |
| ดัน LS | RS | เลือกตัวอักษร (วงนอก) — ตาม [[02-keymap-en-th]] |
| กด D-pad ← | RS | วงคำสั่ง (วงใน 8 ช่อง: โหมด + Copy/Paste/Undo/Redo) — LS ไม่มีผลในวงนี้ |
| Mouse mode | RB + RS | กด RB = วาง caret ที่ pointer, เลื่อน RS = ลากเลือกช่วงข้อความ |
| ทุก mode พิมพ์ | R3 สองครั้ง (< 300 ms) | เริ่ม selection ที่ caret (เปิดลูกศรให้); RS เลื่อน = ขยาย selection |
| มี selection | A / Space | ยืนยัน (selection ยังอยู่) |
| มี selection | B / Backspace | ยกเลิก แล้วลบข้อความที่เลือก |
| มี selection | พิมพ์ตัวอักษร | แทนที่ทั้งช่วง |

- หลักที่ยึดตั้งแต่ v0.7: **วงใน = สิ่งที่ LS เลือก · วงนอก = สิ่งที่ RS เลือก**
  → เมนูกลุ่ม/คำสั่งอยู่ในวงใน · **ข้อยกเว้น v0.10: วงคำสั่งเลือกด้วย RS** ([[10-command-wheel-rs]])

- ใช้ `selAnchor` + `caretPos` คู่เดียว (ไม่ต้องมี state machine เพิ่ม)
- ต้องรักษา caret ให้มองเห็น: ถ้า caret อยู่นอกกรอบข้อความ ให้เลื่อน scroll ตาม (ทำในม็อกอัปแล้ว)
- ข้อควรระวังตอนทำจริง: การเลือกข้อความต้องรู้ "ตำแหน่ง caret ในแอปเป้าหมาย"
  ซึ่ง Win32 ให้ได้ผ่าน `GetGUIThreadInfo`/UI Automation — ถ้าไม่ได้ ให้ fallback เป็น SendInput Shift+ลูกศร
  (เลือกได้เฉพาะแอปที่รองรับ)

## 8. ข้อจำกัดที่ต้องยอมรับ

- เกมที่ใช้ **Raw Input + mouse capture** จะไม่เห็น SendInput (ตั้งใจของเกม) → ต้องสลับเป็น
  โหมด "virtual mouse" ที่ driver ระดับล่าง (นอกขอบเขต v1)
- เกม anti-cheat บางตัวบล็อก SendInput → ใส่ exclusion list ต่อโปรเซส
- pointer กระตุกถ้า polling ต่ำกว่า 125 Hz → บังคับ 250 Hz เป็นค่าต่ำสุด
- จอ 4K + scaling 150% ทำให้ px ต่อนิ้วต่างกัน → ต้องชดเชยด้วย DPI ของจอ
