# ADR-10 — วงคำสั่งเลือกด้วย RS

> ปรับจาก [[07-dpad-left-command-wheel]] (เดิมเลือกด้วย LS) — ปุ่มเปิดยังเป็น **D-pad ←**

## บริบท

เจ้าของขอให้ **การเลือกในวงเปลี่ยนโหมดใช้ Analog ขวา** เพราะนิ้วโป้งซ้ายถูกใช้ค้างกลุ่มอักษรอยู่บ่อย
และ RS ทำหน้าที่ "เลือก" อยู่แล้วในโมเดลเดิม — ลดการสลับบทบาทของนิ้วระหว่างวงกับคีย์บอร์ด

## การตัดสินใจ

| อินพุต | ผล |
| --- | --- |
| **D-pad ←** (หรือ `M`/`C`) | เปิด/ปิดวงคำสั่ง |
| **RS ทิศ** | ไฮไลต์ช่อง (8 ทิศ + hysteresis 9°) |
| **ปล่อย RS** (< 0.25 ค้าง 60 ms) | ยืนยันคำสั่ง |
| **A** | ยืนยันทันที |
| **B** | ยกเลิก |
| **LS** | **ไม่มีผลในวงนี้** (กันเปลี่ยนช่องโดยไม่ตั้งใจ) |

- ยังมี guard: ถ้าเปิดวงขณะ RS ยังดันค้าง (เช่นเพิ่งเลือกตัวอักษร) วงจะยังไม่เลือกช่องใด
  จนกว่า RS จะกลับเข้าใกล้ศูนย์หนึ่งครั้ง
- วงในระหว่างพิมพ์ (กลุ่มอักษร) ยังคงเลือกด้วย **LS** ตามเดิม — ข้อยกเว้นนี้ใช้เฉพาะวงคำสั่ง

## ผลต่อ state machine

- `CMD_WHEEL` อ่าน `Magnitude(RS)` แทน `LS` — ไม่เพิ่ม state
- ดู [[04-state-machine-spec]] §3.1
