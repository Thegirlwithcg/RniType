# ADR-05 — RS เป็นลูกศร + เลือกข้อความด้วย RB/RS

## บริบท

หลังลองม็อกอัป v0.3 เจ้าของขอปรับ 3 เรื่อง:

1. **ถ้าไม่ดัน LS → RS ทำหน้าที่เป็นปุ่มทิศทาง (ลูกศร)** ไม่ใช่ปล่อยว่าง
2. **RB + RS = คลิก/ลากครอบข้อความ** (กด RB ค้างแล้วเลื่อน RS)
3. **กด RS (R3) สองครั้ง แล้วเลื่อน RS = เลือกตัวอักษรในบรรทัด** (ขยาย selection)
4. ให้ **LS เลือกในวงล้อได้ด้วย** (ไม่ใช่มีแต่ RS)

## การตัดสินใจ

| อินพุต | ผล | เหตุผล |
| --- | --- | --- |
| R3 1 ครั้ง | เปิด/ปิดลูกศร (RS ย้าย caret) | กัน caret/บรรทัดเลื่อนโดยไม่ตั้งใจ — ค่าเริ่มต้น RS ว่าง |
| เปิดลูกศร + RS ทิศ | ย้าย caret | ใช้เมื่อต้องการเลื่อนจริงเท่านั้น |
| ดัน LS + RS | เลือกตัวอักษรตาม keymap | คงเดิมตาม [[02-keymap-en-th]] |
| Mouse mode: RB + RS | คลิก/ลากเลือกข้อความ | ตรงกับ RB = คลิกซ้ายตาม [[03-mouse-and-navigation]] |
| R3 ×2 (< 300 ms) แล้ว RS | ขยาย selection จาก caret | เลือกข้อความยาวโดยไม่ต้องกด RB ค้าง; เปิดลูกศรให้อัตโนมัติ |
| A / B | ยืนยัน / ยกเลิก selection | ใช้ปุ่มหน้าที่มีอยู่ ไม่เพิ่มปุ่ม |
| วงล้อโหมด: LS หรือ RS | เลือกช่องโหมด | ลดข้อจำกัดว่าโหมดต้องใช้ RS อย่างเดียว |

## ผลต่อ state machine

- ไม่เพิ่ม state ใหม่ใน core: `CARET_NAV` เป็น "โหมดย่อย" ของ `IDLE`
  (LS < 0.25 + ไม่มี gesture) — ดู [[04-state-machine-spec]]
- ใช้ `selAnchor` + `caretPos` เก็บช่วงที่เลือก; พิมพ์ทับ/Backspace จะแทนที่ทั้งช่วง
- ยังไม่ทำ auto-repeat ของลูกศรใน core (ทำในม็อกอัป 360/90 ms) — ค่อยย้ายลง core ตอน M2

## ความเสี่ยง

| ความเสี่ยง | ระดับ | ทางรับมือ |
| --- | --- | --- |
| RS ขยับโดยไม่ตั้งใจแล้ว caret กระโดด | กลาง | **ต้องกด R3 เปิดลูกศรก่อน** + เกิน 0.45; ปิดได้ด้วย R3 อีกครั้ง |
| กด RB ค้างนาน = ลากยาวเกิน | ต่ำ | ปล่อย RB = จบการเลือก (เหมือนเมาส์จริง) |
| R3 สองครั้งไปชนกับ R3 เดี่ยว (recenter ใน Mouse mode) | ต่ำ | ใน Mouse mode R3 = recenter อย่างเดียว; select mode ใช้เฉพาะ Type mode |
| ต้องรู้ caret ของแอปเป้าหมาย (ทำจริงบน Windows) | สูง | ใช้ `GetGUIThreadInfo`/UIA; ถ้าไม่ได้ให้ fallback เป็น Shift+ลูกศร |
