# ADR-07 — วงคำสั่งวงใน: Mode + Copy/Paste/Undo/Redo บน D-pad ←

> ⚠️ **ปรับแล้ว (v0.10)**: การเลือกในวงเปลี่ยนจาก LS เป็น **RS** — ดู [[10-command-wheel-rs]]
> (ปุ่มเปิด D-pad ← และช่อง 8 ช่องยังเหมือนเดิม)

> แทนที่ [[06-dpad-right-edit-menu]] และส่วน "D-pad 8 ช่อง" ของ [[04-en-vowel-and-8mode]]

## บริบท

หลังลองม็อกอัป v0.6 เจ้าของขอสองอย่าง:

1. **ให้อนาล็อกซ้าย (LS) เลือก "ตัวเลือกวงใน" ได้** — เพราะการหมุนวงนอกเพื่อเลือกเมนู
   (วงล้อโหมด/เมนูแก้ไขที่วาดทับวงนอก) ให้ความรู้สึกว่าไม่คุ้ม: ต้องละนิ้วโป้งขวาจากการพิมพ์
   แล้วยังซ้ำหน้าที่กับ RS ที่ใช้เลือกตัวอักษรอยู่แล้ว
2. **ย้าย Mode + Copy/Paste/Undo/Redo ไปไว้ที่ D-pad ←** (เดิมอยู่ที่ D-pad ↑ และ D-pad →)

หลักการที่เจ้าของต้องการให้ยึด: **วงใน = สิ่งที่ LS เลือก · วงนอก = สิ่งที่ RS เลือก**

## การตัดสินใจ

### 1. วงในวงเดียว 8 ช่อง (โหมด 4 + แก้ข้อความ 4)

เปิดด้วย **D-pad ←** (แตะซ้ำ = ปิด) — ไม่มีวงล้อโหมด/เมนูแก้ไขแยกกันอีก

| ทิศ (LS) | ช่อง | ชนิด |
| --- | --- | --- |
| ↑ | Type EN | โหมด |
| ↗ | Type TH | โหมด |
| → | Mouse | โหมด |
| ↘ | Nav | โหมด |
| ↓ | Copy (`Ctrl+C`) | แก้ข้อความ |
| ↙ | Paste (`Ctrl+V`) | แก้ข้อความ |
| ← | Undo (`Ctrl+Z`) | แก้ข้อความ |
| ↖ | Redo (`Ctrl+Y`) | แก้ข้อความ |

- **LS เลือกช่อง, ปล่อย LS = ยืนยัน** (dwell 60 ms) · **A = ยืนยันทันที** · **B = ยกเลิก**
- **RS ไม่มีผลในวงนี้** (กันเปลี่ยนโหมด/แก้ข้อความโดยไม่ตั้งใจ) — RS ยังเลือกตัวอักษรบนวงนอกตามปกติ
- ช่องที่ใช้ไม่ได้ (คลิปบอร์ดว่าง / ไม่มี undo) จางลงทั้งช่องและป้ายชื่อ

### 2. กันการสั่งงานพลาด: ต้องปล่อย LS ก่อนหนึ่งครั้ง

ถ้าเปิดวงขณะ LS ยังดันค้าง (เช่นเพิ่งพิมพ์ค้างอยู่) วงจะ **ยังไม่เลือกช่องใด** จนกว่า LS
จะกลับเข้าใกล้ศูนย์ (< 0.25) หนึ่งครั้ง — กันการสั่ง Copy/Undo ทันทีโดยไม่ตั้งใจ

### 3. ทางลัดเดิมย้ายออกจากวง (ไม่หายไป)

| ของเดิม (วงล้อ v0.6) | ที่ใหม |
| --- | --- |
| วงล้อ 2 (ตัวใหญ่/F-keys) | **RB/RT** ค้าง = ชั่วคราว, แตะ = ล็อก (ตาม [[04-en-vowel-and-8mode]]) |
| Quick bar (8 ทางลัด) | **LB ค้าง** เปิดบนวงนอก (ตาม [[01-interaction-model]] §5) |
| เปิด/ปิด HUD | หน้าตั้งค่า/tray ของแอป (ม็อกอัป: คีย์ `7`) |
| พัก (หยุดรับ input) | หน้าตั้งค่า/tray หรือปุ่มปิดฉุกเฉิน (ม็อกอัป: คีย์ `8`) |

> วงในมี 8 ช่องพอดีกับสิ่งที่ใช้ทุกวัน — ของที่ใช้นานๆ ครั้งไม่ควรแย่งช่องในท่าเร่งด่วน

## เหตุผล

- **ทิศเดียวกับหลัก "สองแกน = สองการตัดสินใจ"**: เมนูที่ LS เปิด ก็ควรเลือกด้วย LS
  (เมื่อพิมพ์อยู่ วงในคือกลุ่มอักษร — เมื่อเปิดวงคำสั่ง วงในคือคำสั่ง ตำแหน่งนิ้วเดิม)
- **ไม่ต้องละนิ้วโป้งขวา**: RS ยังค้างที่ตำแหน่งตัวอักษรถัดไป ทำให้สลับโหมด/Undo แล้วพิมพ์ต่อได้เร็ว
- **D-pad ← ว่างและจำง่าย** (เดิม ↑ = โหมด, → = แก้ไข — สองปุ่มสำหรับเมนูที่หลักการเดียวกัน)
- **ลดความเสี่ยงกดผิด**: ต้องเปิดวงก่อน (`←`) แล้วเลือก (LS) แล้วปล่อย = 3 จังหวะชัดเจน

## ผลต่อ state machine

- รวม `MODE_MENU` + `EDIT_MENU` เป็น **`CMD_WHEEL`** (ดู [[04-state-machine-spec]])
- ไม่เพิ่ม state ใน `rnitype-core`: วงนี้เป็นชั้น UI/controller ของแอป
  (core ยังรับ "mode changed" / "clipboard command" เป็น event เดียวกัน)
