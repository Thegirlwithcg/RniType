# ADR-09 — LS เลื่อนเปลี่ยนกลุ่มได้โดยไม่ต้องปล่อย

## บริบท

เจ้าของทดลองม็อกอัปแล้วพบว่า **ผลัก LS ไปกลุ่มหนึ่งแล้วกลุ่มถูกล็อก** — จะเปลี่ยนกลุ่มต้องปล่อย LS
แล้วดันใหม่ (ในภาพที่เจ้าของส่งมา ลูกศรชี้การย้ายระหว่าง B → C → D ในวงใน)

ต้นเหตุในโค้ด v0.8: state `GROUP_ARMED` ตั้ง `group` ครั้งเดียวตอน `IDLE → GROUP_ARMED`
แล้วไม่อัปเดตอีกจนกว่าจะกลับไป `IDLE`

## การตัดสินใจ

- ขณะ `GROUP_ARMED`, `CHAR_SELECTED`, `COMMITTING` — ถ้า LS ยังดันอยู่ (≥ `ls_activate` 0.35)
  และทิศเปลี่ยนเป็น sector อื่น (มี hysteresis 9°) → **เปลี่ยนกลุ่มทันที**
- เมื่อเปลี่ยนกลุ่ม: `sector = -1` (ต้องเลือกตัวอักษรใหม่), `hold = 0`
  - ถ้าอยู่ `CHAR_SELECTED`/`COMMITTING` → ถอยกลับเป็น `GROUP_ARMED`
- **ไม่พิมพ์อะไรจากการเปลี่ยนกลุ่ม** — ตัวอักษรจะออกเมื่อ RS ปล่อยตามเดิม
- ใช้ได้กับทั้ง Type-EN และ Type-TH (ใช้ `sectorOf` ชุดเดียวกัน)
- วงคำสั่ง (D-pad ←) ใช้คนละกลไกอยู่แล้ว — ไม่เปลี่ยน

## ผลต่อ state machine

```
GROUP_ARMED --LS เปลี่ยน sector--> GROUP_ARMED (เปลี่ยนกลุ่ม, sector = -1)
CHAR_SELECTED --LS เปลี่ยน sector--> GROUP_ARMED (ยกเลิกตัวที่เลือก)
COMMITTING --LS เปลี่ยน sector--> GROUP_ARMED (ยกเลิก commit)
```

- ไม่เพิ่ม state ใหม่ · ไม่แตะ `rnitype-core` (core ใช้ `group` ที่อัปเดตได้อยู่แล้ว)
- ดู [[04-state-machine-spec]] §2, §3.2

## เหตุผล

- ตรงกับต้นแบบ: วงในคือ "เมนูเลือกกลุ่ม" ที่ควรเลื่อนดูได้เหมือน dial ไม่ใช่ปุ่มกดครั้งเดียว
- ลดจำนวนท่า: พิมพ์ข้ามกลุ่ม (เช่น `a` → `b` → `c`) ทำได้ในการดัน LS ครั้งเดียว
- ตัวเลือกที่ตามมา (RS sector) ยังเห็นบน HUD และ preview ก่อนปล่อย — ย้อนกลับได้

## ความเสี่ยง

| ความเสี่ยง | ระดับ | ทางรับมือ |
| --- | --- | --- |
| นิ้วสั่นตรงเส้นแบ่ง 45° แล้วกลุ่มสลับไปมา | กลาง | hysteresis 9° + ต้องผ่าน `ls_activate` 0.35 (ไม่ใช้ค่าระดับกลาง) |
| เปลี่ยนกลุ่มระหว่างเลือกตัวอักษรโดยไม่ตั้งใจ | กลาง | ต้องดัน LS แรงกว่า 0.35; ตัวที่เลือกถูกยกเลิกและ HUD เปลี่ยนทันที |
| เปลี่ยนกลุ่มระหว่าง commit 60 ms | ต่ำ | ยกเลิก commit แล้วกลับไปเลือกกลุ่ม (ไม่มีคีย์ออก) |
