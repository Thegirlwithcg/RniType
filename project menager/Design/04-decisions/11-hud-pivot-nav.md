# ADR-11 — HUD ตรึงที่ Pivot · Nav = โหมดจัดตำแหน่ง

## บริบท

เดิม HUD วาดที่ **ตำแหน่งเมาส์/pointer** ทุกเฟรม ทำให้ UI ขยับตลอดเวลาและบังข้อความ
เจ้าของขอให้ **UI ไม่ตามเมาส์แล้ว** และให้ **Nav (นำทาง) ทำหน้าที่เป็น Pivot**
เพื่อวางตำแหน่ง UI แทน

## การตัดสินใจ

- HUD มีจุดยึดคงที่ชื่อ **pivot** (ค่าเริ่มต้น ~62% กว้าง / 55% สูง ของจอ)
- HUD **ไม่ผูกกับ pointer** อีก — pointer ใช้เฉพาะโหมดเมาส์ (ซ่อนในโหมดอื่น)
- **Nav = Pivot mode**:
  - **LS** เลื่อน UI หยาบ (~900 px/s)
  - **RS** เลื่อนละเอียด (~320 px/s)
  - **LT** ลดความเร็ว (precision)
  - **R3 / R** = กลับตำแหน่งเริ่มต้น
- pivot ถูก clamp ให้วง HUD ยังอยู่ในจอ (margin 172 × scale) และ clamp ใหม่เมื่อเปลี่ยนขนาด/สเกล
- แสดง crosshair ที่ pivot เฉพาะในโหมด Nav

## เหตุผล

- ตำแหน่ง UI คงที่ = ผู้ใช้จำที่อยู่ได้ และไม่ถูกบังข้อความจากการขยับเมาส์
- Nav เดิมใช้เลื่อนหน้า/สกรอล ซึ่งซ้ำกับ Mouse mode อยู่แล้ว — เปลี่ยนบทบาทให้มีประโยชน์ชัดกว่า
- แยก "ที่อยู่ของ UI" (pivot) ออกจาก "ตำแหน่งชี้" (pointer) ทำให้สองอย่างไม่ตีกัน

## ผลต่อ state machine / UI

- `NAV` ไม่เลื่อน pointer/สกรอลแล้ว → เปลี่ยนเป็น `pivot += dir × speed × dt`
- ไม่เพิ่ม state: ยังเป็น mode `NAV`

## ความเสี่ยง

| ความเสี่ยง | ระดับ | ทางรับมือ |
| --- | --- | --- |
| UI ไปทับข้อความที่กำลังพิมพ์ | กลาง | Nav ย้ายได้ทันที; จำตำแหน่งล่าสุด; ค่าเริ่มต้นชิดขวา |
| ผู้ใช้หาที่ตั้ง UI ไม่เจอ | ต่ำ | crosshair ใน Nav + toast ตอนย้าย + R3 กลับตำแหน่ง |
| HUD หลุดขอบจอเมื่อเปลี่ยนสเกล/จอ | ต่ำ | clamp margin 172 × scale ทุกครั้งที่ resize/scale |

## ผลที่ตามมา

- ม็อกอัป v0.10: `pointer` ซ่อนนอกโหมดเมาส์, HUD ใช้ `pivot`, Nav เลื่อน pivot
- ทดสอบ: `hud-smoke.mjs` — RS เลื่อน pivot, เลื่อนเมาส์แล้ว UI ไม่ขยับ, R กลับตำแหน่ง
