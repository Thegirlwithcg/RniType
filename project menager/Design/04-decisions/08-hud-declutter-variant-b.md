# ADR-08 — HUD ลดความรก: ล็อก variant B + โหมดเรียนรู้

## บริบท

หลัง v0.7 เจ้าของรู้สึกว่า UI "รก" จึงให้ที่ปรึกษา 2 ตัววิจารณ์ (Claude Fable ผ่าน CLI
`--model fable --effort medium` และ subagent `claude-haiku-5-5#medium`) แล้วทำ 2 variant ให้เทียบ

ข้อวิจารณ์ที่ตรงกัน:

1. ข้อมูลเดียวกันถูกบอกซ้ำ 4–5 ที่ (ไฮไลต์ + preview + ghost + chip + hint)
2. Idle วาดโครงเต็มทั้งที่ยังไม่มีข้อมูล (วง 16 ช่อง + glass + chip 3 อัน)
3. ข้อความล้อมวง 4 ก้อนเปลี่ยนทุกเฟรม และ chip `L1` ไม่ให้ข้อมูล
4. Aim wedge 2 อันซ้ำกับไฮไลต์ และชี้ไม่ตรงช่องเพราะ hysteresis
5. ภาษาไฮไลต์หลายแบบเกิน (armed/selected/commit/hover/glow/ขยายฟอนต์)

ทางเลือกที่ทำ: **A = ตัดของซ้ำ** · **B = A + progressive disclosure**
เจ้าของเลือก **B**

## การตัดสินใจ

### 1. ใช้ variant B เป็นค่าเริ่มต้น

- **Idle** = เหลือจุด cursor + pill สถานะ (`Type EN`) — ไม่มีวง/glass/hint
- **ดัน LS** → วงในโผล่ (กลุ่มอักษร) · **ดัน RS** → วงนอกโผล่ (ตัวอักษรของกลุ่ม)
- **กลุ่มที่ armed เด่น** กลุ่มอื่นจาง (~35%) เพื่อลดจำนวนป้ายที่แย่งสายตา
- เปิด **"แสดงวงตลอดเวลา (โหมดเรียนรู้)"** ในแผงตั้งค่าได้ = พฤติกรรมแบบ A

### 2. ตัดของซ้ำ (ทั้งสอง variant)

| ตัด | แทนด้วย |
| --- | --- |
| Ghost ตัวอักษรบินไป caret | preview ที่ caret (จุดที่ตาจ้องอยู่แล้ว) |
| Aim wedge 2 อัน | ไฮไลต์ช่อง + commit ring (เปิด wedge ได้ในแผงถ้าต้องการ) |
| Chip 3 อัน + hint ยาว | **pill สถานะบรรทัดเดียว**: mode · สิ่งที่เลือก · modifier |
| Chip `L1` | แสดงเฉพาะตอนอยู่ชั้น 2 |
| วงนอกจาง 12% ตอนเปิดวงคำสั่ง | ซ่อนวงนอกสนิท + ชื่อคำสั่งถูกเลือกกลางวง |
| `·` 8 จุดตอน idle | ไม่มี placeholder |

### 3. เก็บสิ่งที่จำเป็น

- ไฮไลต์ตัวอักษรที่เลือก + **preview ที่ caret** (ต้องรู้ก่อนปล่อย)
- **commit ring** (บางลง 1.8) — สื่อ "ปล่อย = พิมพ์"
- กลุ่มที่ armed + ชื่อกลุ่ม
- ตัวบอก **ชั้น 2 / Shift / ลูกศร** ใน pill (เปลี่ยนชุดตัวอักษร = เสี่ยงพิมพ์ผิดชุด)
- ช่องคำสั่งที่ disabled (Paste/Undo/Redo) + toast หลัง Copy/Undo
