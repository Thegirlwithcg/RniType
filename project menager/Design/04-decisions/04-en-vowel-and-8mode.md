# ADR-04 — กลุ่มสระ EN + D-pad 8 ช่อง (mockup v0.2)

> ⚠️ **ปรับแล้ว (v0.10)**: LT/Shift เปลี่ยนจาก "กดค้าง" เป็น **กดครั้งเดียวล็อกตัวพิมพ์ใหญ่** — ดู [[13-shift-toggle]]

## บริบท

เจ้าของขอสองอย่างหลังลองม็อกอัป v0.1:

1. ในโหมดพิมพ์ อยากให้ **RB/RT เปิดวงล้อชั้นที่ 2** ได้
2. ภาษาอังกฤษ อยากให้ **กลุ่ม ↑ = สระ AEIOU + ตัวอื่นให้ครบ 8** และ **LT ค้าง = ตัวพิมพ์ใหญ่**
3. ถามว่า **D-pad มี 8 ทิศ = 8 mode** จะเป็นปัญหาร้ายแรงต่อโครงการไหม

## คำตอบ / การตัดสินใจ

### 1. EN กลุ่ม ↑ = สระ (A E I O U + T N S)

| เดิม (v0.1) | ใหม่ (v0.2) |
| --- | --- |
| E T A O I N S H (ความถี่ล้วน) | **A E I O U T N S** (สระก่อน แล้วเติมความถี่) |

- เหตุผล: สระคือตัวที่พิมพ์บ่อยและต้องแม่นที่สุด — รวมไว้กลุ่มเดียวทำให้ไม่ต้องข้ามกลุ่มเวลาพิมพ์คำอังกฤษทั่วไป
- ตัวอักษร 26 ตัวยังครบ 64 ช่อง ไม่ซ้ำ (ย้าย H→B, U→A, R→B, D→B, L→B, C→B, M→B, F→B, W→B)
- ตัวที่ออกจริงเป็น **ตัวพิมพ์เล็ก**, LT (Shift) ค้าง = ตัวพิมพ์ใหญ่
- ตารางเต็มอยู่ใน [[02-keymap-en-th]]

> ข้อควรระวัง: นี่เป็นการจัดกลุ่มตาม "ชนิดอักษร" ไม่ใช่ความถี่ล้วน
> ต้องวัดด้วย harness (WPM/error) เทียบกับ v0.1 ก่อนล็อก — ดู [[02-roadmap-and-smoke-tests]]

### 2. RB/RT = วงล้อชั้น 2

- **ค้าง = ชั่วคราว** (เหมือน Shift), **แตะสั้น = ล็อก/ปลดล็อก**
- ใช้ค่า `double_tap` 220 ms ในม็อกอัป (ช่วงที่แนะนำ 200–400 ตาม [[04-state-machine-spec]])
- ชั้น 2 ของ EN: A–H / I–P / Q–X / F-keys / แป้น Nav / Sym
- ชั้น 2 ของ TH: ฬ ฃ ฅ ํ ๅ / ฦ ฯ ๆ / เลขไทย / ๙ ๐ ฿

### 3. D-pad 8 ทิศ = 8 ช่อง

> ⚠️ **ส่วนนี้ถูกแทนที่แล้ว (v0.7)** — วงล้อโหมดย้ายไปเป็น "วงคำสั่งวงใน" ที่เปิดด้วย
> **D-pad ←** และเลือกด้วย **LS**: ดู [[07-dpad-left-command-wheel]]
> (ส่วนที่ 1–2 ของ ADR นี้ยังมีผล)

**สรุป: ใช้ได้ แต่ให้ D-pad เปิดวงล้อด้วยทิศเดียว (↑) แล้วใช้ RS เลือก** — ไม่ต้องกด 8 ทิศเอง
แบบเดิม (กด 8 ทิศตรงๆ) เสี่ยงกดผิดกลางพิมพ์ เพราะทิศเฉียงกดพร้อมกันยากและไม่มีจังหวะยืนยัน

| ข้อดีของ 8 ช่อง | ข้อเสียถ้ากดทิศตรงๆ (แบบ v0.2) |
| --- | --- |
| 8 ความจำสั้น (ทิศเดียว = หนึ่งอย่าง) | ต้องจำ 8 ช่องแทน 4 → ผิดบ่อยขึ้น |
| ทางลัดที่ใช้บ่อย (ชั้น 2, Quick bar, ปิด HUD) ถึงได้ในท่าเดียว | ทิศเฉียงของ D-pad กดพร้อมกันยาก |
| ไม่ต้องกดซ้ำ/กดหลายจังหวะ | เปลี่ยน mode โดยไม่ตั้งใจ = ผลกระทบสูงตอนพิมพ์ |

**แบบที่ใช้ในม็อกอัป v0.3**

```
D-pad ↑ → วงล้อเปิด (ไฮไลต์โหมดปัจจุบัน)
RS → ทิศไหน = ไฮไลต์ช่องนั้น
ปล่อย RS = ยืนยัน (dwell 60 ms) · B = ยกเลิก · A = ยืนยันทันที
```

| ช่อง (RS) | เนื้อหา | ชนิด |
| --- | --- | --- |
| ↑ | Type EN | โหมดหลัก |
| ↗ | Type TH | โหมดหลัก |
| → | Mouse | โหมดหลัก |
| ↘ | Nav | โหมดหลัก |
| ↓ | วงล้อ 2 | ทางลัด |
| ↙ | Quick bar | ทางลัด |
| ← | เปิด/ปิด HUD | ทางลัด |
| ↖ | พัก (หยุดรับ input) | ทางลัด |

- ค่าเริ่มต้นแสดงครบ 8 ช่อง (ปิดเหลือ 4 ได้ในแผงตั้งค่า) — ความเสี่ยงกดผิดลดลงเพราะมีขั้น "เปิดวงล้อ → เลือก → ปล่อย"
- เกณฑ์ตัดสิน: ถ้ายังเปลี่ยนโหมดผิด > 1 ครั้ง/ชั่วโมง → เหลือ 4 โหมดหลัก และย้ายทางลัดไปปุ่มอื่น (LB ค้าง = Quick bar อยู่แล้ว)
