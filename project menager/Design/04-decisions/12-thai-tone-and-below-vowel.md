# ADR-12 — วรรณยุกต์กลุ่มเดียว + ขีดกำกับ ุ ู

## บริบท

เจ้าของขอสองอย่างในภาษาไทย:

1. **ไม้โท ( ้ ) และไม้เอก ( ่ ) ควรอยู่กลุ่มวรรณยุกต์เดียวกับ ๊ ๋** (เดิม ่ ้ ไปอยู่กลุ่ม "นำ")
2. **สระอุ ( ุ ) และสระอู ( ู ) มองไม่ชัด** — อยากให้ HUD มีขีดกำกับ แล้วให้สระอยู่ใต้ขีด

## การตัดสินใจ

### 1. กลุ่ม TH ชั้น 1 (v0.10)

| กลุ่ม | เดิม | ใหม่ |
| --- | --- | --- |
| ↗ สระ | า ะ ิ ี ื ึ ุ ู | **เหมือนเดิม** |
| → นำ | เ แ โ ใ ไ อ **่ ้** | เ แ โ ใ ไ อ **ฤ ฮ** |
| ↘ วรรณ | ๊ ๋ ์ ็ ำ ั **ฤ ฮ** | **่ ้ ๊ ๋ ์ ำ ั ็** |

- วรรณยุกต์ทั้ง 4 (่ ้ ๊ ๋) อยู่กลุ่มเดียว ตำแหน่ง 1–4 (↑ ↗ → ↘) = ทิศที่กดง่าย
- ฤ และ ฮ ย้ายไปกลุ่ม "นำ" (เปลี่ยนชื่อกลุ่มเป็น **สระนำ + ตัวพิเศษ**)
- ไม่มีตัวอักษรซ้ำ/หาย — ตรวจใน smoke test

### 2. ขีดกำกับสระล่างใน HUD

- ตัวอักษรที่เป็น **สระล่าง** (ุ ู ฺ) → วาดเส้นประสั้นเหนือตัวอักษร (~7 หน่วย) ให้เห็นว่า
  "ตัวนี้อยู่ใต้ฐาน" เหมือนเวลาลองเขียนบนกระดาษ
- วรรณยุกต์ (่ ้ ๊ ๋ ์ ั ็ ำ) **ไม่ต้องมีขีด** — อยู่บนฐานและอ่านออกอยู่แล้ว (ลดความรก)
- ขีดจะสว่างขึ้นเล็กน้อยเมื่อช่องนั้นถูกเลือก และหายไปเมื่อไม่ได้พิมพ์

## ผลที่ตามมา

- `hud.js`: `TH_1` ชุดใหม่ + `char-guide` (SVG line) + `isBelowMark()`
- `02-keymap-en-th.md`: ตาราง TH ชั้น 1 และ §4 (ชั้น 2) อัปเดต
- smoke test: ตรวจกลุ่มวรรณ = `่้๊๋์ำั็`, กลุ่มนำ = `เแโใไอฤฮ`, จำนวนขีด = 2 ในกลุ่มสระ
- **ยังไม่แตะ `rnitype-core`** — ตาราง keymap ใน core ต้องอัปเดตตอน M1 (งานถัดไป)
