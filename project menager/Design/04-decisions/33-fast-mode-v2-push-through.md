## 11. 0.3.5 — "A ไม่พิมพ์" + "UI ค้างหลังปล่อย LS" (2026-11-17)

พฤติกรรมที่เปลี่ยน (รายละเอียด root cause ดู [[Handoff Feature]] §10):

| เรื่อง | เดิม | 0.3.5 |
| --- | --- | --- |
| LS เด้งกลับศูนย์ (0.9 → 0 ผ่าน 0.7–0.2) | ตกโซนตัวอักษร + **ล้างช่อง** → A ไม่พิมพ์ | อยู่ช่วงกลาง < `FAST_PULLBACK_MS` (100 ms) = เด้งกลับ → **คงช่อง** · ค้าง ≥ 100 ms = ดึงกลับเลือกหมวดใหม่ |
| เปลี่ยนช่อง | รับทิศที่ r ≥ 0.30 | รับทิศเฉพาะ r ≥ 0.70 (`FAST_LETTER_OUT`) — ทิศสั่นตอนเด้งกลับไม่เปลี่ยนตัวอักษร |
| "ศูนย์" ที่นับ 120 ms/1500 ms | r < 0.20 (dead band 0.20–0.30 ไม่นับ → UI ค้างถ้าหยุดแถวนั้น) | r < 0.30 (`FAST_CENTER_OUT`) |
| A ชน lockout 100 ms หลัง latch / A ระหว่างรอ latch 60 ms | **ทิ้ง** (edge เฟรมเดียว) | **เก็บไว้ (`pending_accept`)** แล้วพิมพ์ครั้งเดียวเมื่อ lockout หมด |
| RS ยิงลูกศร / B / X / Y เฟรมเดียวกับ A | `tick_fast` return ก่อนถึง `typing.tick_fast` → A หาย | `typing.tick_fast` ทำงานทุกเฟรม · action อื่นเข้าคิว 1 ช่อง ส่งเฟรมถัดไป |
| แตะ RB/RT เปลี่ยนชั้นหลังปล่อย LS | ล้างช่อง → A ไม่พิมพ์ | ไม่ล้างช่อง (A อ่านคีย์ตามชั้นตอนกด) |
| เปิดวงคำสั่ง/ภาษา/quick bar ขณะ Fast UI เปิด | state Fast ค้าง ผุดกลับตอนปิดวง | `fast_reset()` ตอนเปิดวง |
| HUD `fast.zone` / gauge | รายงาน zone ตามเครื่องยนต์ (ยัง `letter` ได้ถึง 1.5 s หลังปล่อย) → **gauge ค้าง** | รายงาน `hidden` + `group/sector = -1` เมื่อ `ui_hidden` · `hud.js` gauge ต้อง `ringsOn` ด้วย |
| วงล้อตอนดัน RS หลัง LS ว่าง ≥ 120 ms | ไม่โชว์ (ติด `!ui_hidden`) | โชว์ตราบที่ RS ชี้ทิศ · ปล่อย RS = หายเฟรมถัดไป |
| กด A แล้วไฮไลต์ค้างที่ช่องเดิม | commit ไม่ล้าง `sector` | **ล้าง `sector` เฉพาะเมื่อกด A ตอน stick อยู่ศูนย์ (`r < 0.30`)** · ดันค้าง = คงไฮไลต์ · A หลังปล่อยพิมพ์ได้ด้วย `last_pick` |
