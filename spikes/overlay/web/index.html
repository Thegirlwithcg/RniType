● RniType — Spike B overlay

  1. พื้นหลังรอบ panel ต้องโปร่งใส (เห็น desktop)
  2. กด “ทดสอบคลิกทะลุ 5 วิ” → คลิก/พิมพ์ใน Notepad ด้านหลังได้
  3. ระหว่างนั้น Notepad ยังเป็น foreground (ไม่แย่ง focus)
  4. ย้ายไปจอ 2 → panel อยู่ถูกตำแหน่งที่ DPI 150%/200%
